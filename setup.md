# LDRP RAG Assistant - Setup Guide

This guide explains how to set up and run the LDRP RAG Assistant project on a new computer.

---

# 1. Prerequisites

Install the following software:

- Git
- Python 3.10+
- Visual Studio Code

Verify installations:

```bash
git --version
python --version
2. Clone the Repository

Open PowerShell / Terminal.

Clone the repository:

git clone https://github.com/smitzzz07/RAG_based_LDRP_chatbox-.git

Enter the project:

cd RAG_based_LDRP_chatbox-

Open the project in VS Code:

code .

If code is not available, open VS Code manually and select the project folder.

3. Create Python Virtual Environment

Create a virtual environment:

py -m venv .venv

Activate it on Windows:

.venv\Scripts\activate

After activation, the terminal should show something similar to:

(.venv) PS C:\...\RAG_based_LDRP_chatbox->
4. Upgrade pip

Run:

python -m pip install --upgrade pip
5. Install Project Dependencies

Install all dependencies:

pip install -r requirements.txt

If requirements.txt is not available, install the current RAG dependencies manually:

pip install pymupdf sentence-transformers faiss-cpu numpy

Then create the requirements file:

pip freeze > requirements.txt
6. Project Structure

The project should look like:

RAG_based_LDRP_chatbox-
│
├── data/
│   ├── raw/
│   │   └── mca_syllabus.pdf
│   │
│   └── processed/
│
├── rag/
│   ├── loader.py
│   ├── cleaner.py
│   ├── chunker.py
│   ├── embeddings.py
│   ├── vector_store.py
│   └── retriever.py
│
├── .gitignore
├── README.md
├── SETUP.md
└── requirements.txt
7. Add the Source PDF

The current project expects the syllabus PDF at:

data/raw/mca_syllabus.pdf

Therefore:

data/
└── raw/
    └── mca_syllabus.pdf

If the PDF is not included in the repository, place your local copy in this folder.

8. Run the RAG Pipeline

The pipeline must currently be executed in this order:

PDF
 ↓
Loader
 ↓
Cleaner
 ↓
Chunker
 ↓
Embeddings
 ↓
FAISS
 ↓
Retriever
9. Step 1 - Load PDF

Run:

py rag/loader.py

Purpose:

PDF
 ↓
PyMuPDF
 ↓
Extracted text

Expected output:

data/raw/extracted_text.txt
10. Step 2 - Clean Text

Run:

py rag/cleaner.py

Purpose:

Remove unnecessary whitespace
Remove excessive blank lines
Normalize extracted text
Preserve meaningful syllabus information

Expected output:

data/processed/cleaned_text.txt
11. Step 3 - Create Chunks

Run:

py rag/chunker.py

Current chunk configuration:

Chunk size: 1000 characters
Overlap: 150 characters

Purpose:

Large document
      ↓
Smaller chunks

Expected output:

data/processed/chunks.json
12. Step 4 - Generate Embeddings

Run:

py rag/embeddings.py

The project currently uses:

all-MiniLM-L6-v2

The model converts every text chunk into a numerical vector.

Current vector size:

384 dimensions

Conceptually:

Text
 ↓
Embedding Model
 ↓
384-dimensional vector

Expected output:

data/processed/embeddings.json

The first run may take longer because the embedding model needs to be downloaded.

13. Step 5 - Create FAISS Vector Store

Run:

py rag/vector_store.py

Purpose:

Embeddings
 ↓
FAISS
 ↓
Searchable vector index

Current implementation:

faiss.IndexFlatL2()

Expected output:

data/processed/faiss.index
14. Step 6 - Test Semantic Retrieval

Run:

py rag/retriever.py

The program will ask:

Ask a question about LDRP syllabus:

Example:

What is the credit of Software Testing?

The system performs:

User Question
      ↓
Question Embedding
      ↓
FAISS Search
      ↓
Top-K Similar Chunks
      ↓
Relevant Syllabus Information

pip install package-name

18. Generated Files

The following files are generated by the pipeline:

data/raw/extracted_text.txt


data/processed/cleaned_text.txt


data/processed/chunks.json


data/processed/embeddings.json


data/processed/faiss.index

These files can be regenerated by running the pipeline.

Therefore, they may be excluded using .gitignore.

19. Environment Variables

Currently the implemented retrieval pipeline does not require an external LLM API key.

When an LLM is added later, use a local .env file.

Example:

LLM_API_KEY=your_api_key_here

Never commit:

.env

to GitHub.

Never publish API keys, passwords or other secrets.

20. Troubleshooting
Git is not recognized

If you see:

git is not recognized

Install Git for Windows and restart VS Code.

Verify:

git --version
Python is not recognized

Try:

py --version

If that also fails, install Python and enable:

Add Python to PATH
ModuleNotFoundError

Example:

ModuleNotFoundError: No module named 'sentence_transformers'

Make sure the virtual environment is activated:

.venv\Scripts\activate

Then:

pip install -r requirements.txt
PDF not found

If you get:

FileNotFoundError

check that:

data/raw/mca_syllabus.pdf

exists.

Also make sure you are running commands from the project root:

RAG_based_LDRP_chatbox-
FAISS index not found

Run the pipeline in order:

py rag/loader.py
py rag/cleaner.py
py rag/chunker.py
py rag/embeddings.py
py rag/vector_store.py

Then:

py rag/retriever.py
